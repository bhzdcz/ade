# Contributing to ADE

ADE is currently developed in a private repository. Ask behzad@airoweb.com for access. Public website improvements can be proposed at https://github.com/bhzdcz/ade-site.

Start with a small reproducible problem or a concrete workflow example. For behavior changes, add an intent, spec and plan; work on a branch and have a human accept the approach. Do not mark human approval on someone else's behalf.

Run the template checks, hook tests and CLI tests listed in README. Tests must use temporary directories, cover meaningful behavior and leave the checkout unchanged. Do not add network dependencies to the CLI without explaining why.

Open a PR with the problem, result, test evidence and limitations. Maintainer review is required before merging. For private vulnerabilities use SECURITY.md.

Useful early contributions: real adoption examples, clearer first-run errors, tests for portable path handling, and accessible public docs. Be respectful and keep feedback focused on the work.
