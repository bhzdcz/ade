# Worked example: password reset

An illustrative feature handoff, not a claim that ADE includes an authentication implementation. Read the three artifacts in order. They remain drafts so copying this example never grants approval.

1. [Intent](intent.md): the user problem and boundaries.
2. [Spec](spec.md): observable acceptance criteria and failure cases.
3. [Plan](plan.md): implementation outline, tests and human review.

A reviewer can trace every planned test to the expected behavior. The actual feature code belongs in your application. Replace the example with your architecture before acceptance.
